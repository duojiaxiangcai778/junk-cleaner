# 磁盘垃圾清理（垃圾清理工具）

扫 C、D 盘用不到的东西，每一项都说清楚「这是什么 / 删了会怎样」，勾选后一键清理。
v2.0.0 起拆成四个页签，把「C 盘 200 多 GB 到底被谁吃了」「QQ 聊天记录到底占多少」
「AI 软件乱拉的东西在哪」这三个问题直接摊开给人看。
v2.1.0 起 QQ / 微信不再只是「只看」——快速清理页直接给出**能勾着清**的聚合项。
v2.2.0 起被占用的文件会自动解除占用再删（关掉占用者的句柄），删不掉登记成重启后删除；
清理项有超时保护，卡在系统调用上只会跳过那一项，不会再让整个软件停在「正在清理」。

v2.3.0 起加了一层 **受保护路径守卫**（src\guard.py）：DSH / pnpm store / node_modules /
各种 AI 编辑器的配置目录，**不管清单里怎么配、通配符怎么展开，删除动作那一层直接拒绝**。
起因是 v2.2.0 把 pnpm 的包存储当垃圾清了，导致 DSH 桌面端插件依赖树被清空、
启动进 Safe Mode、插件设置全部显示丢失（详见
工作记录\2026-11-04-误删DSH插件设置-根因与保护机制.md）。

v2.3.1 修正保护口径：QQ / 微信聊天记录**本来就是要删的**，不该被 guard 拦（那样会把
「聊天记录」页签整个废掉）；真正守住的是 DSH / ZCode 的**记忆、插件、技能**
（见 工作记录\2026-11-04-v232-删除提速与界面修复.md 第一节）。

v2.3.2 三件事：① 删除提速 —— 去掉逐文件路径判断、受保护目录改 `topdown` 不下钻
（顺带修掉一个真漏洞：旧写法自底向上，先删完子目录文件才发现该保护，等于没保护），
2 万小文件 6.6 秒；② 底部按钮栏不再被挤出屏幕（窗口尺寸自适应 + pack 顺序修正），
「清理选中项」禁用态改暗蓝底亮字，不再看着像坏掉；③ 「清理完自动退出软件」选项
文字改直白、提到常驻可见。

## 四个页签

| 页签 | 干什么 | 数据来源 |
|---|---|---|
| **快速清理** | 固定垃圾（临时文件、浏览器缓存、开发缓存、更新包残留、回收站…）+ **QQ / 微信 聚合项** | `junk_items.py` 写死路径，QQ/微信由 `chatdata.py` 现场探测 |
| **C 盘占用** | 逐个软件拆账：这个软件一共占多少、其中多少是缓存/日志能清；外加系统自己的大头（WinSxS、Installer、pagefile…） | `deepscan.py` 现场遍历，不写死路径 |
| **聊天记录** | QQ / 微信的图片、视频、表情、语音、文件、日志，**按月份**拆开，能只清某几个月 | `chatdata.py` 自动找 `Tencent Files` / `xwechat_files` |
| **AI 残留** | AI 软件的工作区、日志、缓存、半成品、装完没删的安装包 | `aitrash.py` 按关键词现场识别 |

### 快速清理页里的 QQ / 微信

以前的版本只有一条「QQ 数据 41 GB · 不动 · 只看」，等于看着恶心人。v2.1.0 改成每条聊天软件
出三到四行，**每行都能勾、都能清**：

| 行 | 档位 | 里面是什么 |
|---|---|---|
| `QQ 缓存（缩略图 / 表情 / 日志 / 临时）` | 可清理 · 默认勾 | `Pic\*\Thumb` 缩略图、`Video\*\Thumb`、`Emoji`、`log`、`nt_temp`、头像 |
| `QQ 聊天内容（原图 / 视频 / 语音 / 文件）` | 需确认 · 不勾 | `Pic\*\Ori` 原图、`Video\*\Ori`、`Ptt` 语音、`File` |
| `QQ 接收文件夹里的散落文件` | 需确认 · 不勾 | 接收目录根下直接堆着的视频/截图/安装包（不是聊天记录，但删了对应消息点不开） |
| `QQ 聊天记录数据库` | 不动 · 不可勾 | `nt_db`，文字记录本体 |
| `微信 缓存（图片缓存 / 临时 / 日志）` | 可清理 · 默认勾 | `cache`、`temp`、`apm_record` |
| `微信 聊天内容（图片 / 视频 / 文件）` | 需确认 · 不勾 | `msg\attach`（按月合并）、`msg\video`、`msg\file` |
| `微信 数据库 / 小程序数据` | 不动 · 不可勾 | `db_storage`、`business`、`resource` |

想按月精挑细选，还是去「聊天记录」页签。**清理前建议先退出 QQ / 微信**，
被占用的文件会自动跳过（不报错、不中断），只是清不干净。

顶部那行小字就是盘级账本，例如：

```
C 盘已用 209.07 GB（Users 84.4 GB / Windows 38.93 GB / ProgramData 20.09 GB / Program Files (x86) 14.17 GB）· 软件垃圾可清 56.88 GB · 共 225 行
```

### 怎么用

1. 双击 `垃圾清理工具.exe`，等 30～40 秒扫完（四个页签一次扫完）。
2. 列表里默认已经勾好了所有「可清理」项（绿色文字）。
3. 切到想看的页签；点某一行，**下方会显示这一项是什么、删了会怎样、实际路径在哪**。
4. 双击任意一行可以直接打开那个文件夹，自己先看一眼再决定。
5. 想清的点「选中可清理项」→「清理选中项」→ 二次确认 → 开始。
6. 清完自动重新扫描，顶部会报释放了多少。

### 三种处理建议

| 标记 | 含义 | 默认 |
|---|---|---|
| 可清理 | 删了没副作用，或者会自动重建 | 已勾选 |
| 需确认 | 删了有代价（丢原图、丢回滚能力、要重新下模型），自己判断 | 不勾 |
| 不动 | 游戏本体、模拟器虚拟磁盘、聊天记录数据库、模型权重，只展示大小 | 不可勾 |

清理失败的文件（正被程序占用、权限不足）会自动跳过，不会中断整次清理。
**联接目录（junction）一律不跟进去删**，避免清 C 盘却删到 D 盘上的东西。

## 以后要加 / 改固定清理项

**只改 `src\junk_items.py`，然后重新打包就行，不用碰其它文件。**

每项长这样：

```python
dict(
    id="temp_user",                      # 唯一标识，日志里用
    name="用户临时文件",                   # 列表里显示的名字
    category="临时文件",                   # 分类
    level="safe",                        # safe / caution / view
    kind="dir",                          # 见下面五种
    paths=[r"%LOCALAPPDATA%\Temp"],      # 支持 %环境变量% 和 * 通配符
    desc="这是什么，删了会怎样。",          # 详情区显示的说明
),
```

`kind` 五种行为：
- `dir` —— 清空目录内容，**保留目录本身**（Temp 这类系统还要用）
- `file` —— 删除文件（支持 `*.db` 这种通配）
- `recycle` —— 清空指定盘回收站，`paths` 写盘符根，如 `["C:\\"]`
- `vss` —— 删除系统还原点（走 vssadmin，需要管理员）
- `dism` —— 跑 `DISM /Online /Cleanup-Image /StartComponentCleanup` 清 WinSxS 旧组件；
  界面上显示的是 WinSxS 总大小，但**不参与「已选合计」**，因为实际能腾多少只有跑完才知道

### 想改 C 盘 / 聊天 / AI 三页的扫描规则

- 增删「哪些目录算缓存」→ 改 `deepscan.py` 顶部的 `CACHE_NAMES` / `LOG_NAMES` /
  `TEMP_NAMES` / `CRASH_NAMES` / `PROTECT_NAMES`，以及 `_classify()`
- 增删「AI 软件怎么认」→ 改 `aitrash.py` 的 `AI_HINTS` / `NOT_AI`
- 增删「AI 缓存固定路径」→ 改 `aitrash.py` 的 `HOME_CACHE`
- QQ / 微信结构变了 → 改 `chatdata.py` 的 `_qq_rows()` / `_wx_rows()`
- 想改快速清理页 QQ/微信 那几行的名字和说明 → 改 `chatdata.py` 的 `QUICK_DEFS`
- QQ 探测不到 → 看 `chatdata._discover()`：它在所有固定盘里按名字找
  `tencent files` / `xwechat_files` / `wechat files`，深度 3；`Tencent Files\nt_qq\global`
  （没绑账号的全局缓存）也单独算一个账号

### 重新打包命令

```powershell
cd E:\垃圾清理工具\src
D:\D\Python311\python.exe -m PyInstaller --noconfirm --onefile --windowed --uac-admin `
  --icon "E:\垃圾清理工具\src\icon.ico" `
  --add-data "E:\垃圾清理工具\src\icon.ico;." `
  --name "垃圾清理工具" `
  --distpath "E:\垃圾清理工具" --workpath "E:\垃圾清理工具\build" `
  --specpath "E:\垃圾清理工具\build" --paths "E:\垃圾清理工具\src" `
  "E:\垃圾清理工具\src\main.py"
```

> `--add-data "icon.ico;."` 是 v2.2.0 加的：窗口图标走 `iconbitmap(resource_path("icon.ico"))`，
> 单文件包解开后图标在 `_MEIPASS` 里，不加这行就打不进包，任务栏会退回 Tk 默认图标。

改完记得把 `main.py` 里的 `VERSION` 往上加（改代码必须升版本号），界面上能直接看到。

打包完可以删掉 `build\` 和 `src\__pycache__\`，都是中间产物。
