# 2026-11-02 磁盘垃圾清理工具 · 初版

## 需求

用户原话：把之前那套「扫 C / D 盘垃圾并逐项说明」的能力做成一个软件，每一项都要有说明，
以后自己点清理，不用每次都让 AI 扫（省 token）。只在以后要更新这个软件时再找 AI。

## 设计决策

- **技术栈**：Python 3.11 + tkinter + PyInstaller 单文件。本机已有 Python 3.11.9 / tkinter / PyInstaller 6.20.0，
  零额外依赖，打包体积 11.5 MB。
- **为什么不用 Electron**：体积 100 MB 起，为了个清理工具不值。
- **为什么不写 PowerShell + WinForms**：用户要的是双击就能开的 exe，ps1 还得配执行策略。
- **配置化**：所有清理项和说明集中在 `src/junk_items.py`，以后加项只改这一个文件。

## 实现

### 文件

| 文件 | 作用 |
|---|---|
| `src/junk_items.py` | 45 条清理项定义（id / 名称 / 分类 / 等级 / kind / paths / desc） |
| `src/scanner.py` | 并行扫描（8 线程），算每项占用；回收站走 `SHQueryRecycleBinW`，还原点走 `Win32_ShadowStorage` |
| `src/cleaner.py` | 执行删除，逐文件容错，写日志到 `%LOCALAPPDATA%\DiskJunkCleaner\log\` |
| `src/main.py` | tkinter 界面 + 主流程 + 确认对话框 |

### 关键实现点

1. **kind 四态**
   - `dir` 清空内容保留目录（Temp 类目录系统还要用，不能连目录一起删）
   - `file` 删文件，pristine glob
   - `recycle` 走 `SHEmptyRecycleBinW`，不遍历 `$Recycle.Bin`
   - `vss` 走 `vssadmin delete shadows /for=C: /all /quiet`
2. **路径支持** `%ENVVAR%` 和 `*` 通配，`resolve_paths()` 统一展开去重
3. **三项等级**：safe 默认勾选 / caution 默认不勾 / view 不可勾（游戏本体、模拟器虚拟磁盘）
4. **清理容错**：逐文件 `try/except`，占用或权限不足就跳过并计数，不中断整批
5. **清理后自动重扫**，状态栏报释放量

### 遇到的坑

1. **raw string 不能以反斜杠结尾**：`paths=[r"C:\"]` 语法报错，改成 `["C:\\"]`
2. **确认框按钮被挤出窗口**：33 项 × 30px 撑破固定高度，`pack` 顺序导致底部按钮不可见。
   修法：按钮先 `pack(side="bottom")` 占位；列表只显示前 9 项 + "另外 N 项"。
3. **深色标题栏只设背景会看不见标题文字**：`DWMWA_CAPTION_COLOR`(35) 单独设会让黑字压深色底。
   必须同时设 `DWMWA_TEXT_COLOR`(36) 为浅色。
4. **tkinter 控件对 UIA 不可见**：`windows_computer_use_find` 找不到按钮，只能按坐标点。
   测试时被别的进程窗口挡住导致首次点击没命中，改用「启动后 `after()` 自动触发」验证。

## 追加：v1.0.1 换图标（同日 18:25–18:32）

### 需求
用户要求把图标做得像样点，可以自己画、借现成清理软件的改、或用在线 AI 出一张。

### 决策：自己用 Pillow 精绘，不走在线生图
- AI 生图出的图标是 1024 单图，缩到 16/24/32 会糊成一团，还得抠图去底
- 应用图标必须多尺寸分级绘制，这个只有程序化绘制能精确控制
- 无网络依赖，改一版 30 秒

### 过程：画了 14 个方案对比
- 第一轮 A/B/C/D：白线桶 / 蓝实心桶 / 青实心桶 / 桶+星
- 第二轮 E/F/G/H/I/J：收窄桶 / 加桶口 / 扫帚 / 磁盘扫光 / 星群 / 桶+右上星
- 第三轮 K/L/M/N：蓝桶蓝星 / 蓝桶白星 / 线桶淡蓝 / 线桶大星
- 判据是「16px 与 32px 下能否一眼认出」——白线桶在小尺寸糊成一灰团，
  实心蓝桶最清晰，星星在 16px 直接消失，所以小尺寸必须去掉星

### 定稿
- 深色圆角底 `#1a1d22` + 蓝色实心桶 `#4a9eff` + 白色桶盖/提手 + 右上白四角星
- **分级绘制**：16/24/32 走简化版（无竖纹无星、线加粗、桶加大）；48+ 走完整版
- 手写 ICO 二进制打包（ICONDIR + ICONDIRENTRY + 各档 PNG），7 档尺寸独立渲染

### 验证
- exe 图标用 `Icon.ExtractAssociatedIcon` 提取回来看：32px 是蓝桶，正确嵌入
- 启动 v1.0.1 实测：41 项 / 468.01 GB / 可清理 23.03 GB，标题栏图标同步更新
- 版本号已升 1.0.0 → 1.0.1，界面右上角和标题栏都能看到
