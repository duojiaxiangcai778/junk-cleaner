## 卡死现场（2026-11-03 23:24–23:55）

- 主程序 PID 19572（v2.1.0），23:24:11 启动，状态栏停在
  「正在清理：WinSxS 组件仓库（DISM 清理）」，界面 `已选 27 项 · 75.51 GB`。
- 清理日志 `clean-2026-11-03.log`（243 行）：23:26:35–23:27:22 只清了
  QQ 缓存 22.98 GB、QQ 聊天内容 14.95 GB（均「失败 0 个」），最后一条
  `[23:27:22] … nt_data\dataline -> 释放 83853698 字节`，之后进入 DISM 再无写入。
- DISM 子进程 23084 / DismHost 18104 / TiWorker 9104，启动 23:27:22；
  `C:\Windows\Logs\CBS\CBS.log` 停在 23:28:12
  （`Beginning Null-Delta compression of boot-recovery components`），
  TiWorker CPU 冻在 59.1 → 判定 Windows 组件服务自己卡死。
- 老版 `dism_component_cleanup()` 用 `subprocess.run(timeout=1800, capture_output=True)`，
  既看不到进度也没法取消，界面只能干等；1800 秒超时之前用户只会看到「卡住」。

### 处置

- `taskkill /F /PID 19572 /T` 杀掉主程序 + 全部 Dism 子进程。
- TiWorker 9104 杀不掉（`taskkill` 报 no running instance，`Get-Process` 还在，
  `Stop-Service TrustedInstaller` 也拒绝）→ 僵尸态，DISM 后续任何调用都会等它。
  手动 `dism.exe /Online /Cleanup-Image /StartComponentCleanup` 同样卡住，
  **WinSxS 这一项只能重启电脑后再跑**。
- 剩余任务用新代码 headless 补完，见下「本次清理结果」。

## 代码改动（v2.1.0 → v2.2.0）

### 新增 `src/unlocker.py`（自动解除占用）

1. Restart Manager（`RmStartSession` / `RmRegisterResources` / `RmGetList`）
   问系统「这个文件被谁开着」，拿 pid；
2. `NtQuerySystemInformation(SystemExtendedHandleInformation=64)`
   拿全系统句柄表（本机约 18.3 万条）；
3. 只处理占用进程的句柄：`DuplicateHandle` 到本进程 →
   `GetFinalPathNameByHandleW` 取真实路径 → 和待删路径比对；
4. 命中就 `CreateRemoteThread` 在占用进程里跑 `kernel32!CloseHandle(原句柄)`
   （句柄表是进程私有的，用户态没别的办法；kernel32 在 KnownDLLs 里基址一致才敢这么干；
   32 位 WOW64 进程跳过，不冒险）；
5. 关完重试删除；还删不掉 `MoveFileEx(MOVEFILE_DELAY_UNTIL_REBOOT)` 登记重启后删除。
6. `_find_lockers_guarded()`：Restart Manager 对个别路径会卡住不返回，
   单文件 1.5 秒超时、整轮 20 秒预算，超时当「查不到」跳过。

### 重写 `src/cleaner.py`

- `_rm_tree()` / `_empty_dir()` 收集失败路径（老版只返回个数，无法补救）；
- `_retry_after_unlock()`：解锁 → 重试删除 → 登记重启删除，整段 90 秒上限；
- `_prune_empty()`：解锁后剩下的空壳目录顺手收掉；
- `clean_item()` 外层超时包装：普通项 600 秒、DISM 1800 秒，真卡住就跳过这一项、
  记日志继续下一项 —— 不会再出现「整个软件陪一项一起卡死」；
- `dism_component_cleanup()` 改 Popen + 线程读输出：
  实时解析 `xx.x%` 喂给界面、支持取消、连续 300 秒无输出判定卡死并终止；
- `empty_recycle_bin()`：Shell 之后补一刀管理员直删 `X:\$Recycle.Bin\*`。
  老版只调 `SHEmptyRecycleBinW`，它只清当前用户的回收站，其它 SID 的残留
  （本机 E 盘 16 GB）它根本不动，失败还不写日志。

### 改 `src/main.py`

- `VERSION = "2.2.0"`；
- `resource_path()` + `self.iconbitmap(...)`：任务栏不再是 Tk 默认羽毛；
- `FlatButton` 主按钮白字（原来 `#08121f` 深蓝近黑，`set_enabled(True)` 还会覆盖成灰色），
  禁用态 `#9fc4ee`；
- 底部新增勾选「清理完自动退出」「强制清理（自动解除占用）」，
  存 `%LOCALAPPDATA%\DiskJunkCleaner\config.json`；
- 底部常驻提示条：「清理时遇到被占用（QQ / 微信 开着也算）的文件，会自动解除占用后再删；
  仍删不掉的会登记为下次开机自动删除」；
- 清理中显示「取消清理」红按钮，`cancel_event` 贯穿扫描/清理/DISM；
- `_clean_done()`：汇总释放量 / 登记重启删除数量 / 失败原因写入详情区，
  勾了自动退出就 3 秒后关窗；
- 确认框增加「强制清理已开」的说明。

## 已知问题 / 下一步

1. **WinSxS（DISM）项需要重启电脑后再跑**：TiWorker 当前是僵尸态，
   任何 DISM 调用都会卡；新版界面会实时显示百分比、300 秒无输出自动判卡死并终止。

   主屏 2560×1440 正常；如需适配小屏可再调 minsize。
